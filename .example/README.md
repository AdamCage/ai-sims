# Проекты для изучения

Скачаны 1 ноября 2026 по предложению автора. Это локальные исследовательские копии, не зависимости игры. Их приложения, установочные скрипты и примеры не запускались.

| Каталог | Официальный проект | Корневая лицензия |
| --- | --- | --- |
| `MiroFish/` | [666ghj/MiroFish](https://github.com/666ghj/MiroFish) | AGPL-3.0 |
| `oasis/` | [camel-ai/oasis](https://github.com/camel-ai/oasis) | Apache-2.0 |
| `ai-town/` | [a16z-infra/ai-town](https://github.com/a16z-infra/ai-town) | MIT |
| `generative_agents/` | [joonspk-research/generative_agents](https://github.com/joonspk-research/generative_agents) | Apache-2.0; отдельные условия графики |
| `concordia/` | [google-deepmind/concordia](https://github.com/google-deepmind/concordia) | Apache-2.0 |

Ревизии и способ загрузки: [manifest.json](manifest.json). Разбор конкретных файлов и кандидатов: [документация референсов](../docs/05-reference-analysis.md).

Копии созданы через `git clone --depth 1 --filter=blob:none`. Рабочие деревья содержат файлы выбранной ревизии; история Git сокращена. Большой репозиторий может занимать значительное место и при shallow clone: Smallville содержит множество сохранённых состояний и ассетов.

Корневые лицензии не означают, что условия всех изображений, зависимостей и других вложенных материалов одинаковы. Изучение подхода и прямой перенос кода фиксируются отдельно. Ничего из этих копий пока не включено в продукт.

В `.gitignore` исключены каталоги копий; этот README и манифест оставлены доступными для будущего Git-репозитория. При передаче проекта исходники можно получить из указанных официальных репозиториев и сверить `HEAD` с зафиксированным SHA. Shallow-клон актуальной ветки в будущем может иметь другой HEAD; для точного восстановления нужна зафиксированная ревизия.

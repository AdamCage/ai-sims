# Состояние движка

Дата: 15 ноября 2026. Первый исполняемый вертикальный срез. Настоящий запуск выполнен на Windows, Godot 4.7.2, OpenGL Compatibility / NVIDIA RTX 4080 SUPER.

## Работает

- Общая комната, склад, отдельная комната за закрытой дверью, четыре предмета, включая два ограниченных пайка. Геометрия стен общая для правил и renderer.
- Три различимых персонажа со стабильными профилями, потребностями, телесными ограничениями, личным инвентарём и отдельными runtime.
- Независимый от FPS логический шаг, пауза, продолжение, один шаг, reset. Детерминированный Mock AI выполняет реальные действия последовательно; интеграционная проверка проходит 40 раундов.
- Перемещение относительно взгляда, поворот, осмотр, взятие, выкладывание, передача, речь и ожидание. Проверяются дистанция, стены, тела, доступность предмета, руки и зрение. Последний предмет не дублируется.
- Сценарий `closed_block`: Ada видит паёк, Boris его не видит. Сообщение становится слуховым опытом с источником, а не зрительным фактом; Mock AI может отправиться проверять. В проверочном эпизоде происходят взятие, речь, движение и передача пайка.
- Сценарий `last_ration`: Ada и Boris одновременно претендуют на единственный доступный паёк; задаётся аргументом запуска.
- Верхняя камера наблюдателя и три настоящие камеры 512×320. Закрытые стены сохраняются в личных кадрах. Накладки/имена/подсветка наблюдателя не попадают в изображения агентов.
- Реальный Observer UI: кнопки, клавиши, выбор персонажа, смена вида, профиль/состояние/инвентарь/память, последнее намерение и результат, хронологический журнал.
- Append-only личные наблюдения и исходные PNG. Копии не позволяют переписать прошлое через внешний reference. Отдельный Memory Agent имеет контракт с собственным опытом, без доступа к истине мира.
- RouterAI adapter с настройкой модели, мультимодальным payload, строгим JSON, timeout, safe wait, отменой и защитой поколений. Сбор асинхронных намерений встроен в игровой раунд. Есть конечный дополнительный лимит запросов; сеть отключена по умолчанию.
- Сохранение мира/журнала/личной памяти/кадров/намерений в одном session file. Повреждённая загрузка отклоняется до замены мира. Replay показывает промежуточные состояния без модели и без изменения живой сессии.
- Одна повреждённая нога замедляет движение и повышает усталость; две сломанные — ползание с низкой камерой и позой; четыре сломанные конечности запрещают перемещение. Две сломанные руки запрещают манипуляции предметами; одна оставляет одноручные действия.

## Ограничения

- Платные API-вызовы не проводились: нет разрешённого бюджета. Работа выбранного alias с этим prompt, качество зрения, задержка и стоимость фактического вызова не подтверждены. Протокол проверен локальными ответами. Пользовательский переключатель платного режима пока не добавлен; есть явный программный integration API.
- Mock AI использует геометрическую подсказку видимости. Она учитывает стены/двери, но не окклюзию другими персонажами; этот диагностический режим не доказывает распознавание изображений или поведение LLM. VLM получает настоящие пиксели без списка объектов.
- Субъективной суммаризации и пересмотра вторичных черт ещё нет. Свежий опыт сохраняется точно; текущий VLM context получает текущее PNG и последние 12 текстовых записей. Извлечение старых визуальных воспоминаний не реализовано. История пока растёт без каскадного сокращения.
- Нет действий consume, лечения, боя, смерти и открытия дверей. Потребности пока служат состоянием и расходом; полного выживания нет. Численные стоимости/скорости — обратимые defaults из ADR.
- Терминал пайков, очередь, сетевые сообщения/подмена, устройства, дневник и игровые фото не реализованы. Extension API возвращает `not_implemented` и ничего не меняет; это не готовые механики.
- Нет редактора внешности. Различимость задаётся цветами/геометрией и параметрами исходного состояния; изменение цвета во время сессии не является готовой кастомизацией.
- Один этаж, примитивные модели, без навигационного планировщика, звука и плавной ходьбы: тела переходят между авторитетными позициями по шагам. Слух моделируется сообщениями в пределах 7 м с проверкой стены, без акустики.
- Журнал хранит полные снимки и накопленные события: подходит для коротких отладочных сессий, не для долгой лабораторной записи. Экспорт standalone exe и другие платформы не проверялись.

3. Реализовать авторитетный терминал пайков и очередь, затем разделённые права доставки/чтения/удаления/подмены сообщений.
4. Уменьшить размер журнала, добавить действия с дверями и помощь телу, расширить параметры внешности и удобство наблюдения.

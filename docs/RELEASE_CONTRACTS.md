## Product decisions

Windows 10/11 x64 standalone, RU/EN, three separate selectable maps (closed_block, residence, research_station), sandbox plus authored scenarios, 3–20 agents. Full god mode edits environment/resources/roles/body/profile/memory/goals and records interventions. Real RouterAI with user's key; development/acceptance calls capped at 1000 RUB TOTAL. No key currently in environment. No silent substitution of real decisions by demo policies. Free assets only. Stylized textured 3D, optional anime face/eye styling only within same rig/import pipeline. Modular character appearance presets. Normal PC target: 16 GB RAM, GTX1650 4GB, 1080p60 medium (must verify, not claim from RTX4080).

Combat: health100, successful ordinary cold-weapon hit20. Instant kill ONLY if victim asleep or unconscious. Awake backstab is ordinary damage. Simple treatment/splints/rest/rescue. Existing arm/leg/blind guards apply to every new action. God can explicitly edit foundation; AI/memory cannot.

## Shared state

JSON compatible. Position `[x,z]` metres. heading degrees,0=-Z,+90=-X. `ReleaseSimulation.state = {version:2,run_id:int,tick:int,minute:float,map_id,scenario,agents:Dictionary,items:Dictionary,geometry:{bounds:[minx,maxx,minz,maxz],walls:Array,doors:Array,props:Array},events:Array,event_cursor:int,terminal:Dictionary,economy:Dictionary,network:Dictionary,artifacts:Dictionary,objectives:Array}`. `events` is a bounded recent observer tail; a separate journal captures history (never recursively copies events into every checkpoint).

Agent `{id,name,color,position,heading,profile:{foundation,traits,goal},needs:{hunger,fatigue},health:float,pain:float,body:{blind,left_arm,right_arm,left_leg,right_leg},inventory:Array[String],appearance:{face:int,hair:int,outfit:int,skin:String,hair_color:String,height:float,build:float},alive:bool,sleeping:bool,unconscious:bool,busy:Dictionary,last_action:Dictionary,last_result:Dictionary,relations:Dictionary,tokens:int,roles:Array}`. Default appearance keys always present. Optional private observer fields allowed. Limb values healthy/injured/broken. `busy.type` signals visual animation and action lifecycle; current authoritative position progresses through navigation, not render-driven movement.

Item `{id,label,kind,position,holder,owner,container,surface_height:float,quantity:int}`; add device/artifact/access fields as needed. kinds ration,water,medkit,splint,knife,phone,camera,mug,key,photo,diary. Holder/owner distinct. Furniture/props `{id,kind,center:[x,z],size:[w,d],height:float,angle:float}`; geometry blocks movement/view consistently; door `{id,center,size,height,open,locked}`. Runtime scene uses these records, not an independent secret collision map.

## APIs/ownership

Simulation owner ONLY: `scripts/game/`, `tests/test_release_simulation.gd`. `session_simulation.gd` extends RefCounted (preload-friendly, class_name optional). APIs `reset(map_id:String="closed_block",count:int=7,scenario:String="scarcity",seed:int=1)->Dictionary`, `snapshot()->Dictionary`, `observe(actor_id:String)->Dictionary`, `submit(actor_id:String,action:Dictionary,expected_run_id:int=-1)->Dictionary`, `advance(minutes:float)->Array`, `intervene(command:String,args:Dictionary)->Dictionary`, `export_state()->Dictionary`, `import_state(data:Dictionary)->bool`, `get_map_catalog()->Array`. `.state` public for observer/debug only. `submit` validates/queues plan or applies short action through rules, returns {ok,reason}; `advance` updates needs/plans/time and emits facts. Drained/tail events have `{seq,tick,minute,type,actor,ok,message,details}`. Provide `action_catalog.gd` static `validate(action:Variant)->Dictionary {ok,action,error}` and `instructions()->String`; runtime uses this exact schema. Inform root/other owners immediately when APIs ready/changed.

Observation `{tick,minute,self_state:{name,health,pain,needs,body,alive,sleeping,unconscious,tokens},profile,inventory:Array[{slot,label,kind,quantity}],heard:Array,last_result,contacts:Array,personal_results:Array,targets:Array[{ref:String,uv:[u,v]}],mock_view:Array}`. No global IDs/absolute coordinates/full maps/foreign minds or inventories. `mock_view` only diagnostic/demo: geometrically visible `{ref,kind,label,distance,bearing}`; never included real prompts or memory-role context. Engine creates temporary per-agent refs `v0...` mapped internally per observation. Default `targets` same refs with placeholder UV until world enriches them. Methods `perception_candidates(actor_id)->Array[{ref,position:[x,z],height:float}]` expose internal render metadata to root only. World can update UV/omit candidates outside actual camera. Blind no fresh visual targets or PNG. Action target uses temporary ref; inventory uses own slot. Social/device operations use private known contacts/messages IDs scoped to that agent, not global world object identifiers. Target handles do not enumerate hidden entities.

UV uses x0=left,x1=right,y0=top,y1=bottom. For action grounding, root may supply an ephemeral `grounding_png` derived from the exact current camera with only the already allowed `vN` handles drawn at those UV coordinates, bound by `grounding_source_hash`. The original camera PNG remains the actual visual experience; the extra image is explicitly artificial assistance, never a physical label, and never enters personal memory/archive/export. It adds no names, kinds, distances, hidden targets or global IDs. `World.grounding_image(image,targets)` asynchronously renders this private 2D helper; photos and original cameras are unchanged.

`SessionSimulation.personal_experience(actor_id,experience)` synchronously emits each real heard/read event before bounded notification tails are trimmed. `experience={tick,minute,heard:Array,personal_results:Array}` contains only that owner's event. Root routes it to `Runtime.observe_personal_event(experience,run_id)` without resetting visual refs or making a network call. Protected event records contain no fabricated body/inventory snapshot. Explicit god memory clearing also clears transient heard/read tails.

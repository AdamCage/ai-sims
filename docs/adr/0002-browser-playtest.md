# Браузерная версия и личные решения

17 ноября 2026. Технические решения для тестовой версии.

Основная поставка для наблюдателя — статическое приложение Godot Web с WebGL 2. Общие ресурсы и отдельные карты доставляются с одного HTTPS-адреса. Вкладка удерживает Web Lock на игровые записи. Ключ RouterAI после входа через PKCE доступен в памяти текущей вкладки. Локальные слоты и расчёты бюджета переживают перезапуск через IndexedDB.

Планировщик обслуживает свободных жителей по времени ожидания. На отправку одного решения расходуется один зарезервированный запрос с текущими личными изображениями. До четырёх шагов связываются с кадром, личным инвентарём и моментом наблюдения. Истёкшая ссылка или физический отказ останавливают продолжение плана. Занятые жители могут действовать во время ожидания сети. В демонстрации личный опыт дополняется периодическими настоящими снимками и текущими наблюдениями геометрии.

Три эпизода занимают по двенадцать игровых часов. Варианты внешности используют общий скелет и переключаемые комплекты одежды, обуви и волос. На основе первого прохождения владелец оценивает ясность целей, читаемость сцены и хронологии и выбирает доработки для следующего выпуска.
